# 🌱 FocusForest AI – Productivity Timer That Plants Trees

## 📖 Project Overview

FocusForest AI is an intelligent productivity timer designed to help users stay focused while making a positive environmental impact. Every time a user starts a focus session, the platform plants a virtual tree (or optionally triggers a real-world tree planting service through a partner API).

By combining time management, habit building, and environmental awareness, FocusForest AI transforms productive work sessions into meaningful contributions toward a greener future.

# 🚀 How It Works

## Step 1: Start a Focus Session

The user selects a timer duration and clicks **Start**.

Example:

30-minute study session

## Step 2: Tree Creation Begins

As soon as the timer starts:

* A virtual tree is planted in the user's digital forest
* Or a tree-planting request is sent to a partner service

## Step 3: Focus and Work

The timer runs in real time while displaying:

* Elapsed time
* Remaining time
* Current date
* Current clock time

## Step 4: Complete the Session

When:

* The timer reaches zero
* OR the user ends the session

The session is recorded.

## Step 5: Statistics Update Automatically

The dashboard updates instantly:

* Total trees planted increases
* Focus time accumulates
* Streak count updates
* Session history is stored
* Date and time are recorded

# ⚙️ Installation & Setup

## Prerequisites

* Node.js (v18+ recommended)
* npm or yarn
* Modern web browser

## Clone Repository

```bash
git clone https://github.com/yourusername/focusforest-ai.git

cd focusforest-ai
```

## Install Dependencies

```bash
npm install
```

## Start Development Server

```bash
npm run dev
```

Application will be available at:

```text
http://localhost:3000
```

## Build for Production

```bash
npm run build
```

## Environment Variables

Create a `.env` file:

```env
DATABASE_URL=your_database_url

TREE_API_KEY=your_tree_planting_service_key

OPENAI_API_KEY=your_ai_key
```
